# 跨品类规律 v4：七品类，规律三得到最强验证

> 新增：浏览器自带密码管理（469 样本 / 166 条）
> 目的：用"免费替代品极端案例"检验规律三

## 1. 结果

| 主题 | 次数 | 占比 | 强度 |
|---|---|---|---|
| 功能缺失与限制 | 28 | 17% | 3.3 |
| 安全与隐私担忧 | 26 | 16% | 3.5 |
| 其他 | 25 | 15% | 3.0 |
| 同步与跨设备体验 | 22 | 13% | 3.3 |
| 密码生成与强度管理 | 22 | 13% | 3.5 |
| 主密码与解锁流程 | 16 | 10% | 3.2 |
| **浏览器切换/重装后数据丢失** | 13 | 8% | **3.9** |
| 自动填充失败或误填 | 7 | 4% | 3.1 |
| 导入导出与迁移 | 3 | 2% | 3.7 |
| **付费与订阅** | **3** | **1.8%** | **2.3** |

## 2. 规律三：最强验证

| 品类 | 付费占比 | 付费强度 | 免费替代品的可得性 |
|---|---|---|---|
| PDF | 40% | 3.8 | 极低（无免费替代） |
| 密码管理器 | 12% | 3.6 | 中（浏览器自带是弱替代） |
| 笔记工具 | 10% | 3.7 | 中（免费笔记很多） |
| 智能门锁 | 10% | 2.8 | 高（机械钥匙） |
| 记账/预算 | 8% | 3.1 | 高（表格/免费 App） |
| 截图工具 | 3% | 3.0 | 极高（系统自带） |
| **浏览器密码管理** | **1.8%** | **2.3** | **本身就是免费替代** |

**付费占比与免费替代的可得性呈明显反向关系，强度也随之下滑（3.8 → 2.3）。**

规律三从"方向验证"升级为"跨七品类成立"。

## 3. 一个反直觉发现：免费产品也有数据锁定

`浏览器切换/重装后数据丢失` 13 条，强度 **3.9**——全品类最高的单项之一。

浏览器密码是免费的，但用户换浏览器时依然会丢数据、被迫重录。

**这说明**：数据可携带性问题与"是否收费"无关，只与"是否积累了大量结构化数据"有关。

这反而加强了规律二的修正版：**数据出口只在数据型产品成立**，与付费无关。

## 4. 七品类裁决

| 规律 | 裁决 | 证据强度 |
|---|---|---|
| 一：核心动作决定留存 | ✅ 七品类全成立 | 强 |
| 二：数据出口决定信任（仅数据型） | ✅ 成立，且与付费无关 | 强 |
| 三：付费强度取决于免费替代 | ✅ 七品类成立 | **强** |
| 四：信任类低频高痛 | ✅ 七品类全成立 | 强 |

## 5. 七品类总表

| 品类 | 第一痛点 | 付费占比/强度 |
|---|---|---|
| PDF | 付费 40% | 40% / 3.8 |
| 密码管理器 | 自动填充 28% | 12% / 3.6 |
| 笔记工具 | 同步 22% | 10% / 3.7 |
| 智能门锁 | App/连接 30% | 10% / 2.8 |
| 记账/预算 | 功能复杂 23% | 8% / 3.1 |
| 截图工具 | 跨平台兼容 19% | 3% / 3.0 |
| 浏览器密码 | 功能缺失 17% | 1.8% / 2.3 |

## 6. 结论

**七品类之后，四条规律全部成立（其中两条带条件）。**

最实用的一条：**判断一个品类能不能做买断制，先看它有没有免费替代。**

- 没有免费替代（PDF）→ 付费痛感 3.8，买断制是差异化；
- 免费替代极强（浏览器密码）→ 付费痛感 2.3，收费本身是劣势。

## 7. 局限

- 浏览器密码的"付费"样本只有 3 条，强度 2.3 的置信区间很宽；
- 七个品类都来自 Reddit + App Store，偏英语技术用户；
- 规律是方向性判断，未做统计检验；
- 主题表是分别设计的，跨表对齐靠人工语义映射。
