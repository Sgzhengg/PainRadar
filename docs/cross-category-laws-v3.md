# 跨品类规律 v3：第六个品类与一次噪声事故

> 新增：截图/标注工具（67 样本 / 37 条）
> 目的：验证修正版规律三——"付费强度取决于免费替代品的可得性"

## 1. 截图工具结果

| 主题 | 次数 | 强度 |
|---|---|---|
| 其他 | 12 | 3.1 |
| 跨平台与系统兼容性 | 7 | 3.3 |
| 截图编辑与标注体验 | 6 | 3.5 |
| 工作流集成与自动化 | 4 | 3.2 |
| 更新维护与客户支持 | 4 | 3.5 |
| 性能与资源占用 | 3 | 3.3 |
| **免费替代品与付费意愿** | **1** | **3.0** |

**付费相关只有 1 条（3%），强度 3.0**——远低于 PDF 的 40%（3.8）。

方向与修正版规律三一致：**免费替代品越容易获得，付费越不构成痛点。**

但样本只有 37 条，只能算"方向支持"，不能算"证实"。

## 2. 一次噪声事故（比结论更重要）

第一次跑截图工具时，"其他"占 40%，抽查发现里面全是无关内容：

- Duolingo 变差、咖啡影响睡眠、GERD 饮食限制、情绪淹没；
- iCloud 备份、Excel 公式、磁盘工具。

**根因**：`_fetch_once` 里有一段"领域过滤兜底"——某个板块被过滤到 0 条时，
会**放宽领域约束重试一次**，结果把整页无关帖子放了进来。

修复：

1. 删除兜底逻辑（宁可样本少，不要噪声）；
2. 读取历史语料时**重新做关键词 + 领域过滤**，清掉之前混进去的脏数据。

修复后：样本从 354 降到 67，但"其他"里的无关内容消失，主题分布变得可解释。

**教训**：为了凑样本量而放宽过滤，是用可信度换数量，得不偿失。

## 4. 规律裁决（更新）

| 规律 | 裁决 |
|---|---|
| 一：核心动作决定留存 | ✅ 六品类全成立 |
| 二：数据出口决定信任 | ⚠️ 仅数据型产品成立 |
| 三：付费强度取决于免费替代 | ✅ 方向验证（截图 3% vs PDF 40%） |
| 四：信任类低频高痛 | ✅ 六品类全成立 |

## 5. 结论

**四条规律，两条硬、两条条件，六品类后仍然站得住。**

但截图工具样本只有 37 条，规律三还需要一个样本更大的"免费替代多"品类来确认
（比如 PDF 阅读器 vs 编辑器，或密码管理器 vs 浏览器自带密码）。

## 6. 方法论收获

1. **噪声比样本量更致命**：354 条脏数据不如 67 条干净数据；
2. **兜底逻辑要慎用**：任何"为了不空而放宽"的规则，都会引入系统性偏差；
3. **"其他"占比是健康指标**：超过 20% 先怀疑数据，再怀疑主题表。
