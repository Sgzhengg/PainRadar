## 4. 为什么这符合"AI 重耕 SaaS"

Incumbent 的收费本质是**人工劳动的替代**：
记账、对账、录发票、核库存，都是"把纸/邮件/PDF 变成结构化数据"。

AI 把这部分边际成本压到接近零，于是出现一个套利空间：

| 旧模式 | 新模式 |
|---|---|
| 按坐席收费 $30–100/人/月 | 按任务或买断 $19–99 |
| 需要培训、实施 | 上传即用 |
| 价值 = 软件 + 人工 | 价值 = 自动化 |

**判断标准很简单：如果现有 SaaS 的核心工作是"读文档、填表格、对数字"，它就可以被重做。**

## 5. 最具体的一个楔子

> **发票/收据 → 结构化 → 自动对账**

- 输入：PDF/照片发票、银行流水 CSV
- 输出：已分类的账目 + 异常清单（重复报销、金额不符、缺失发票）
- 买家：个体户、小事务所、自由职业者
- 定价：$29/月 或 $99 买断（限量）
- 渠道：会计社群、QuickBooks/Xero 应用市场、Reddit r/Bookkeeping
- 为什么能赢：现有工具按坐席收费且要手工录入；AI 直接跳过录入

## 6. 风险

1. **平台封堵**：QuickBooks/Xero 可能限制第三方读取，需以"上传文件"而非"接 API"起步；
2. **准确率责任**：对账错误有金钱后果，需要"异常清单 + 人工确认"而不是全自动；
3. **获客**：B 端需要渠道，Reddit 和会计社群能拿到前 100 个用户，但再往上要靠集成市场；
4. **合规**：涉及财务数据，隐私与留存策略要写清楚。
