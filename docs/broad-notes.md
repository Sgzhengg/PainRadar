# 广度语料：找"你原本不会注意到"的痛点

> 目标：不预设工具、不预设行业，用跨领域的日常摩擦语料，找出反复出现但你不会主动想到的痛点。

## 1. 语料

7 个互不相关的域，每域 2 个板块，共 **2,109 条**评论（抽样 1,050 条做 LLM 抽取）：

| 域 | 板块 | 条数 |
|---|---|---|
| 钱与账单 | personalfinance、povertyfinance | 380 |
| 求职与职业 | jobs、resumes | 333 |
| 家庭与教育 | Parenting、Teachers | 386 |
| 房屋与维修 | HomeImprovement | 193 |
| 出行与身份 | travel、immigration | 368 |
| 神经多样与无障碍 | ADHD | 182 |
| 手续与合规 | legaladvice、tax | 267 |

统一 14 个"摩擦场景"：表格文书、预约等待、费用账单、信息找不到、沟通跟进、
规则资格、出错纠错、多方协调、时间期限、线上线下切换、语言理解、隐私安全、系统不可用。

## 2. 跨域痛点（4 条同时出现在 2 个以上域）

| 分数 | 需求 | 证据 | 域数 |
|---|---|---|---|
| 69 | **规则资格不透明难自查** | 53 | **4** |
| 55 | 沟通无回应跟进困难 | 18 | 3 |
| 44 | 费用不透明与意外扣费 | 31 | 2 |
| 41 | 表格文书复杂难填写 | 23 | 2 |

剩下 6 条只在单域成立（求职无反馈、时间管理、流程纠错、家庭协调、记忆遗漏、预算追踪）。

**单人可交付（C 端）**

| 分数 | 需求 |
|---|---|
| 84 | 时间管理拖延与 deadline |
| 80 | 表格文书复杂难填写 |

| 77 | 规则资格不透明难自查 |
| 76 | 预算规划与支出追踪难 |

|---|---|
| 67 | 预算规划与支出追踪难 |
| 66 | **规则资格不透明难自查** |

| 62 | 记忆沟通遗漏与误解 |

## 4. 一个清晰的规律

- **通用效率类**（时间管理、记忆、待办）：单人容易做（84），但 AI Harness 一出来就被替代（63）；
- **规则密集类**（资格自查、费用扣费）：单人做起来稍难（77/64），但**抗替代更强**（66/60）。

原因：效率工具卖的是"提醒与整理"，Harness 天生会；规则工具卖的是"知道规则、能持续核对状态"，
这需要**结构化知识 + 持久状态 + 责任**，恰好是 Harness 缺的。

## 5. 这对你意味着什么

1. 广度语料确实能挖出"你不会主动想到"的痛点（规则资格、费用扣费都不是某个 App 的问题）；
2. 但**"能挖到"和"适合你做"仍是两件事**：高分项要么被 Harness 替代，要么需要行业知识；
3. 真正值得看的是 **"规则密集 + 需要持续状态 + 有明确责任人"** 这一类，它同时满足：
   - 单人能做（结构化工具，不需要人工服务）；
   - 不易被 Harness 替代；
   - 用户愿意为"别出错"付钱。

## 6. 局限

- 语料来自 Reddit，偏英语、偏愿意发帖的人；
- 抽样 1,050 条，单域覆盖有限；
- 两个评分都是 LLM 判断，不是实测；
- 跨域数只有 4 条，样本仍薄。

## 7. 工程

- `tools/fetch_broad.py`：7 域 14 个板块、共用摩擦场景词表
- `var/demand_taxonomy_broad.json`：广度需求表（10 条）
- `solo-fit --profile consumer | ai_saas` 双口径评分
- 测试 124 个全过
