## 典型叙述

### 1. 修复PC上VR头显无法被识别的问题

> I uninstalled Horizon link, Disabled my integrated intel GPU in device manager

- 期待：让头显正常连接PC

- 触发：`other`
- 替代：—
- 处置：`still_using`

### 2. 无线串流PCVR游戏

> I personally use this method as I’ve found that, in recent months, it’s become much more stable than Air Link

- 期待：稳定流畅的无线PCVR体验
- 实际：Steam Link比Air Link、VD、ALVR更稳定
- 触发：`other`
- 替代：Steam Link
- 处置：`still_using`

### 3. 用Link玩PCVR游戏

- 实际：Link会崩溃，USB beta版更不稳定，VD不适用

- 替代：—
- 处置：`unknown`

### 4. 和朋友一起在VR里看2D电影

- 替代：—
- 处置：`shelved`
