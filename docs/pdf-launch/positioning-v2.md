# payoncepdf 定位 v2：用手册结论重写

> **2026-11-20 提价说明**：本文写于 2026-11-16 定价决策当时，文中的 `$29 / ¥169`（早鸟 `$19 / ¥109`）是**历史价格**，论证与数字按原文保留。现行价格为 **$39 / ¥199**（首发 14 天早鸟 **$29 / ¥149**），一把钥匙最多 3 台设备；依据 `docs/updf-parity-decision.md` §1、`config/product.json` 与 PRD §22.10。

> 依据：`docs/category-opportunity-playbook.md` + PDF 专项报告（300 样本 / 81 条）
> 目标：把"不订阅"从口号变成有证据的定位

## 1. 五问审计（PDF）

| 问题 | 答案 | 证据 |
|---|---|---|
| 有没有免费替代？ | **弱替代有，强替代无** | 系统预览能看不能改；免费网页工具要上传 |
| 核心动作是什么？ | 编辑/转换/表单，且要可靠 | 编辑与表单 11%（3.6），配置门槛 9% |
| 用户会不会积累数据？ | 会，但文件本身可带走 | 迁移不是主要痛点（4%） |
| 信任风险高不高？ | **中**：文档含合同/病历 | 本地处理正好是解药 |
| 是否被订阅伤害过？ | **是，最严重** | 付费痛点 40%，强度 3.8 |

**结论：五问全过。这是七个品类里唯一全过的。**

关键推论：

- **买断制的差异化不是"便宜"，是"不再被订阅"**；
- **本地处理不是技术卖点，是信任卖点**（对应"文件不该出门"）；
- **性能是隐藏风险**：只有 5 条但强度 4.0，买断制没有订阅兜底，崩一次就退款。

## 2. 定位一句话

**EN**：The PDF editor you buy once — offline, no subscription, no pop-ups.

**CN**：一次买断的 PDF 工具——本地处理、不订阅、不弹窗。

三层含义，对应三个最大痛点：

| 层 | 对应痛点 | 数据 |
|---|---|---|
| buy once | 付费与订阅 40% | 强度 3.8 |
| offline | 隐私/信任 + 授权失效 | 本地处理，服务器下线不影响 |
| no pop-ups | 弹窗与广告 6% | 强度 3.8 |

## 3. 信息层级（按数据排序，不按喜好）

1. **首屏**：buy once + offline（两个最大痛点）
2. **第二屏**：no pop-ups / no account / no daily limits
3. **第三屏**：功能四件事（合并、拆分、压缩、转换/OCR、签名）
4. **第四屏**：数据锚点（37% 差评与收费有关）
5. **第五屏**：风险反转（7 天退款、90 天未交付自动退、授权永久有效）

## 4. 对现有 copy.md 的具体改动

| 位置 | 现在 | 改成 | 原因 |
|---|---|---|---|
| 主标题 | PDF tools without the subscription. | **Buy once. Works offline. No subscription.** | 把"离线"抬到首屏，对应信任与授权失效 |
| 三个卖点 | 不订阅 / 不上传 / 不注册 | **不订阅 / 不上传 / 不弹窗** | 弹窗强度 3.8，比"不注册"更痛 |
| 副标题 | Merge, split… $29 once. | 保留功能，加 **"license never expires"** | 直接回应"永久授权失效" |
| 数据锚点 | 37% 差评与收费有关 | 保留，并加一句 **"27% 提到弹窗/广告"** | 第二个可验证痛点 |
| 反对意见 | 已有 5 条 | 加 **"你们跑路了我的授权怎么办"** → 离线授权，不依赖服务器 | 数据里的明确恐惧 |
| OCR 表述 | "复杂表格不支持" | 保留，但加 **"OCR 是重点投入项"** | OCR 占 24%，不能显得敷衍 |

## 5. 定价建议

**维持 $29 买断 / 首发 $19，不改。**

理由（来自数据，不是拍脑袋）：

1. PDF 付费痛点强度 3.8，说明用户对价格敏感但**更恨订阅**；
2. 免费替代弱，$29 不需要靠低价换量；
3. $19 早鸟是"决策门槛"，不是"价值锚点"——早鸟结束必须回到 $29，否则等于承认不值。

**不要做的**：不要加"年付便宜"选项——那会把买断制拉回订阅叙事。

## 6. 不该说的话（数据不支持）

| 别说 | 为什么 |
|---|---|
| "比 Adobe 快 10 倍" | 性能只有 5 条样本，强度 4.0 是"少数人极痛"，不是普遍优势 |
| "AI 驱动" | 数据里 AI 相关只有 1 条，用户不关心 |
| "最全能的 PDF 工具" | 核心动作才决定留存，全能等于没有重点 |
| "永久免费更新" | 成本撑不住，且与"12 个月更新"的诚实边界冲突 |

## 7. 上线后验证什么

| 指标 | 看什么 | 对应规律 |
|---|---|---|
| 退款率 | <3% | 付费痛点是否被回应 |
| 差评关键词 | 出现 subscription/refund/crash 即失败 | 规律一、三 |
| 客服工单 | OCR 相关占比 | OCR 是否被低估 |
| 首周留存 | 打开→完成任务 | 配置门槛 |

## 8. 一句话

**PDF 的机会不在"功能更多"，在于它是七个品类里唯一"没有免费替代、又被订阅伤害最深"的品类——买断制不是策略，是这个品类的正确答案。**
