# 价值衰减 v3：两段判定的结果与代价

> 改动：先判定"是不是衰减叙述"（gate），再分类（tag）；禁止 other，允许 unclear。

## 2. 结论

### 好的：other 被消灭，精度提升

- v2 的 other 占 32–49%，v3 直接归零；
- "价值未兑现"占比从 22–35% 升到 **53–62%**，说明被筛掉的确实是噪声；
- 处置动作更可信（Watch 吃灰 7/17，Kindle 已卖 8/13）。

### 代价：召回骤降

| 产品 | v2 有效 | v3 有效 |
|---|---|---|
| Watch | 46 | 17 |
| Kindle | 59 | 13 |
| VR | 47 | **4** |

VR 只剩 4 条，已经不能用来判断分布。**两段判定换来了精度，但样本量撑不住结论。**

## 3. 为什么会掉这么多

1. **gate 太严**：要求"本人拥有 + 明确弃用"，而 Reddit 评论多是片段，缺少上下文；
2. **候选池不稳定**：同一抓取参数，VR 候选从 85 掉到 26（Arctic Shift 的 latest 流在变）；
3. **正则筛的是"提及"，不是"叙述"**：大量命中只是顺带提到"我卖了""吃灰"，没有解释。

## 4. 正确的下一步（按性价比排序）

| 优先级 | 动作 | 理由 |
|---|---|---|
| 1 | **接二手平台**（eBay/闲鱼） | 挂牌理由是最硬的行为证据，且天然是"拥有 + 弃用" |
| 2 | **扩大候选池**：pages 30+、加板块、加关键词变体 | 候选基数不够，再准也没用 |
| 3 | **校准 gate**：人工标 50 条，算精确率/召回率 | 现在是拍脑袋调提示词，没有基准 |
| 4 | 稳定后再并入 PainRadar 主流程 | 指标可信才有意义 |

## 5. 现在的可用判断

虽然样本小，三个产品仍一致指向：

1. **"价值未兑现"是跨产品最稳定的衰减主因**（53–62%）；
2. **冗余是 Apple Watch 的显著项**（24%），对应"手机已能做"；
3. **Kindle 的主要出路是卖掉**（8/13），说明用户对设备本身没意见，只是不用；
4. **VR 样本不足，暂不下结论**，但摩擦仍是可见主因。

## 6. 一句话

**v3 证明了"两段判定"结构可行，但也证明了：没有足够大的候选池和外部行为证据，再好的分类器也只能给出方向，给不出比例。**
